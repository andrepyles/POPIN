# POPIN v4

POPIN measures populist rhetoric in political documents from 19 Latin American countries (2000–2025).

- **Dashboard:** [popin.andrepyles.xyz](https://popin.andrepyles.xyz)
- **Current data and reproducibility package:** [GitHub release v4.1.0](https://github.com/andrepyles/POPIN/releases/tag/v4.1.0)
- **Earlier scoring snapshot:** [GitHub release v4.0](https://github.com/andrepyles/POPIN/releases/tag/v4.0)

## Manuscript snapshot

The v4.1.0 snapshot contains 45,492 scored documents: 44,592 from the full run and 900 from a separately identified pilot. It uses GPT-5.6 Luna, prompt v4, and each document's available full text in one request, without chunking. The main substantive analysis covers 34,821 `SPEECH` documents.

Each document receives six scores from 0 to 100. The final score is their arithmetic mean.

| Dimension | Measures |
|---|---|
| `people_centrism` | The people as a virtuous political collective |
| `anti_elitism` | Elites portrayed as opposed to the people |
| `moral_dichotomy` | Moral division between the people and their opponents |
| `popular_sovereignty` | Claims that political authority derives from the people |
| `exclusionary_rhetoric` | Rhetorical exclusion of groups from the people |
| `crisis_rhetoric` | Politics framed as crisis or existential threat |

The earlier v4.0 release is a separate Qwen3 snapshot scored in 800-word chunks; its results are not combined with v4.1.0.

## Reproduce the results

Download `popin.duckdb` from the v4.1.0 release into the repository root. The database contains the full texts, scores, raw model responses, and run metadata. Then install the pinned dependencies and rebuild the exports and analysis tables:

```bash
python -m pip install -r requirements.txt
python 50_generate_final_tables.py
python tools/reproduce_validation_audit.py
python 51_generate_validation_tables.py
```

The audit inputs are versioned under `data/release_v4/analysis/source_inputs/`. The score CSV and Parquet are also available as separate release assets and are regenerated by the first command above. See [`docs/REPRODUCIBILITY.md`](docs/REPRODUCIBILITY.md) for filters, outputs, hashes, and source notes; see [`docs/DATA_DICTIONARY.md`](docs/DATA_DICTIONARY.md) for field definitions.

The original Luna batch driver is [`25_luna_all_noninvalid_openai_batch.py`](25_luna_all_noninvalid_openai_batch.py). You do not need to rerun it to reproduce the published tables; rerunning it requires an OpenAI API key and submits model requests. Details are in [`docs/LUNA_BATCH_JOB.md`](docs/LUNA_BATCH_JOB.md).
